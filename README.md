# T-Delayer
This is a disk based delayer that can store hours of material and output it a later time while still recording new content.

It is based on Ubuntu 22.04.

## Installation
```
sudo dpkg -i delayer-4.0.0
sudo apt-get -f install
````

### Storage
The files generated by the delayer are stored in /home/video. It is best to have a dedicated disk for this partition.

To generate the file system and mount it
```
mkfs.ext4 -O ^has_journal /dev/sdX
mount -t ext4 -o noatime,nodiratime,discard,data=writeback /dev/sdX /home/video
```

Also but the mount in /etc/fstab
```
/dev/sdX  /home/video  ext4  noatime,nodiratime,discard  0  0
```


## To start an interface do

```
sudo systemctl start delayerd@'st1'.service
```

## Control
Control of the delayer is done via AWS IoT.
