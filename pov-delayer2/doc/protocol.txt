Packet
======

Byte Offset
0		4 bits type of packet, 4 bits reservered for future use
0		4 bytes sessionid 
1		2 bytes payload length
3		1 byte channel number
4		3 bytes counter (individual per channel)
13		4 bytes microsecond timestamp when the packet was originally sent
19		arbitrary payload


Type of packets
0000  = Setup packet
0001  = Close packet
0010  = Heartbeat packet
0011  = Datadelivery packet
0100 = Ack packet

ipheader 16 bytes
udp header 4 bytes
poly header 14 bytes
rtp header 12 bytes

7*188 =1316 

16+4+14+12+1316 = 1362
